# OS-Question

## What is OS-Question?

OS-Question is a personal research space focused on:

- Operating system abstractions
- AI systems and agent runtimes
- Infrastructure, scheduling, and resource models
- The philosophical and structural questions beneath computation

This site serves as a long-term notebook, not a blog platform.
